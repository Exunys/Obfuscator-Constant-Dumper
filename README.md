# Obfuscator Constant Dumper
## Informaton
This dumper only supports IronBrew V2, AztupBrew and PSU / KFC < V4.5.A.

You can edit *Main.lua* and set `_G.Cache` to `true` to get the hooked version of the inputted obfuscated script.

You need [Lua 5.1.5.0](https://github.com/Exunys/Lua-5.1) to run this.
## Notice
AztupBrew Dumper could not be accurate because I had to dig really deep for obfuscated scripts so I could test them & dump them.
PSU Dumper could be broken because of the same reason as AztupBrew. I also almost never used PSU. If this is not efficient, go ahead and use my [replit dumper](https://replit.com/@Exunys/PSU-Constant-Dumper).
